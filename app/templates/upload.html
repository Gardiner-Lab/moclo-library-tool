📄 GenBank File Upload

Upload a GenBank file (.gb, .gbk, or .genbank) containing your MoClo part. The tool will automatically:

  • Detect BsaI restriction sites (GGTCTC/GAGACC)
  • Extract the part sequence between the sites
  • Identify the 4bp overhangs
  • Parse metadata and annotations
  • Suggest the part type based on features

📦 Bulk GenBank Upload

Upload multiple GenBank files (.gb, .gbk, or .genbank) at once. Each file will be parsed and added as a separate part.

Filename tip: put an L0, L1, L2 or Lvl1 token in the filename (set off by _, -, . or a space, for example myCassette_L1.gb) and the MoClo level is filled in for you. You can still change it per file below before uploading.
