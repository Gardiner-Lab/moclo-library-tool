# Plant genome-editing MoClo toolkit — Level 0 module sequences

The GenBank (`.gb`) files in this directory are vector sequences from the plant
CRISPR/Cas modular cloning toolkit described in:

> Hahn F, Korolev A, Sanjurjo Loures L, Nekrasov V.
> **A modular cloning toolkit for genome editing in plants.**
> *BMC Plant Biology* 20, 179 (2020).
> https://doi.org/10.1186/s12870-020-02388-2

## Source

The sequence files were obtained from the authors' Figshare deposit:

> Hahn, Florian; Korolev, Andrey; Sanjurjo Loures, Laura; Nekrasov, Vladimir (2020).
> A modular cloning toolkit for genome editing in plants. figshare. Journal contribution.
> https://doi.org/10.6084/m9.figshare.11961975

## Files included

Level 0 tRNA-sgRNA position-1 modules (by Pol III promoter x sgRNA backbone):
  pFH113, pAK007, pFH49, pFH50, pFH51, pFH71, pFH72, pFH73, pFH74, pFH75

Level 0 tRNA-sgRNA position 2-6 modules:
  pAK002, pAK003, pAK004, pAK005, pAK006

tRNA-sgRNA array endlinkers:
  pAK-EL-01, pAK-EL-02, pAK-EL-03, pAK-EL-04, pAK-EL-05

Pol III promoter modules:
  pFH31 (Wheat TaU3p), pFH34 (Arabidopsis AtU6-26p),
  pFH36 (Rice OsU6-2p), pFH38 (Rice OsU3p)
